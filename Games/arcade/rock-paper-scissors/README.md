# Rock Paper & Scissors

Classic Rock Paper Scissors game against the computer.

## How to Play
1. Click on Rock, Paper, or Scissors
2. Computer randomly picks its choice
3. Rock beats Scissors, Scissors beats Paper, Paper beats Rock
4. Score is tracked throughout the session

## Files
- `index.html` — Game page
- `style.css` — Game-specific styles
- `script.js` — Game logic (random choice, scoring, result display)
- `assets/images/` — Rock, Paper, Scissors images
