# Tic Tac Toe

Classic Tic Tac Toe (X and O) strategy game for two players.

## How to Play
1. Players take turns clicking on empty cells
2. Player 1 is **O**, Player 2 is **X**
3. First to get 3 in a row (horizontal, vertical, or diagonal) wins!

## Files
- `index.html` — Game page
- `style.css` — Game-specific styles
- `script.js` — Game logic (turns, win detection, reset)
